## Directory structure

- `mcs_statistics.py` - currently just call the different functions at the end of the file to plot the various maps/distributions
- `figs/`             - output for the figures
- `notebooks/`        - notebooks for testing (currently)

### 1. Activate the conda environment

```conda activate hk26_env```

### 2. Open `mcs_statistics.py` and select one of (or all) the plots to make, then call their correponding functions at the bottom e.g

```init_time_dists()```

### 3. Save the file

### 4. Run the file

```python mcs_statistics.py```
